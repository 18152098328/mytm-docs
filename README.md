# MyTM Docs

MyTM Docs is an original, local-first workspace for foreign-trade customer records, product records and business documents.

## Features

- Customer and product master data
- Quotation, Proforma Invoice, Sales Contract, Commercial Invoice and Packing List
- Reusable product lines and automatic totals
- Browser-local storage
- JSON backup and restore
- Print / Save as PDF
- Responsive desktop and mobile layout

## Windows quick start

Double-click `START-MYTM-DOCS.cmd`.

For first-time setup, install Node.js 22 or later and run:

```powershell
npm install
npm run build
```

After setup, double-click `START-MYTM-DOCS.cmd` and open `http://localhost:3000`.

## Privacy

Business records remain in the current browser profile unless the user explicitly exports a backup. Back up data before clearing browser storage or changing devices.
